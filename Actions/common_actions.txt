Convert Date Time with Format
    [Arguments]    ${inputDateTime}    ${returnFormat}=yyyymmdd
    [Documentation]    This is the function return ${inputDateTime} with ${returnFormat}
    ...
    ...    ${inputDateTime}:
    ...
    ...    By default this keyword returns the current local time, but that can be altered using `time` argument as explained below. Note that all checks involving strings are case-insensitive.
    ...
    ...    - 1) If `time` is a number, or a string that can be converted to a number, it is interpreted as seconds since the UNIX epoch. This documentation was originally written about 1177654467 seconds after the epoch.
    ...    -
    ...    2) If `time` is a timestamp, that time will be used. Valid timestamp formats are 'YYYY-MM-DD hh:mm:ss' and 'YYYYMMDD hhmmss'.
    ...    -
    ...    3) If `time` is equal to 'NOW' (default), the current local time is used. This time is got using Python's 'time.time()' function.
    ...    -
    ...    4) If `time` is equal to 'UTC', the current time in UTC is used. This time is got using 'time.time() + time.altzone' in Python.
    ...
    ...    - 5) If `time` is in the format like 'NOW - 1 day' or 'UTC + 1 hour 30 min', the current local/UTC time plus/minus the time specified with the time string is used. The time string format is described in an appendix of Robot Framework User Guide.
    ...
    ...    Return Format:
    ...    - yyyymmdd
    ...
    ...
    ...
    ...    -----HISTORY--------------------
    ...    - [20150824]: Casey-Created
    ${yyyy}    ${mm}    ${dd}    Get time    year,month,day    ${inputDateTime}
    ${m}    run keyword if    '${mm}' < '10'    Fetch From Right    ${mm}    0
    ...    ELSE    set variable    ${mm}
    ${d}    run keyword if    '${dd}' < '10'    Fetch From Right    ${dd}    0
    ...    ELSE    set variable    ${dd}
    ${returnDay}    Run Keyword If    '${returnFormat}'=='yyyymmdd'    set variable    ${yyyy}${mm}${dd}
    ${returnDay}    Run Keyword If    '${returnFormat}'=='mm/dd/yyyy'    set variable    ${mm}/${dd}/${yyyy}
    ...    ELSE    Set variable    ${returnDay}
    ${returnDay}    Run Keyword If    '${returnFormat}'=='m/d/yyyy'    set variable    ${m}/${d}/${yyyy}
    ...    ELSE    Set variable    ${returnDay}
    ${returnDay}    Run Keyword If    '${returnFormat}'=='mm_dd_yyyy'    set variable    ${mm}_${dd}_${yyyy}
    ...    ELSE    Set variable    ${returnDay}
    [Return]    ${returnDay}

Create List in Range 0-1
    [Arguments]    ${start}    ${end}    ${step}
    [Documentation]    This action is used to create a list of number (in string) in range 0 -1
    ...
    ...    ${start}: the starting number of the sequence
    ...
    ...    ${end}: the ending number of the sequence
    ...
    ...    ${step}: the different between each number in the sequence
    ...
    ...    ${outputlist}: the output list that containg list of string number
    ${tmpN}    Evaluate    int(1/${step})
    ${tmpStart}    Evaluate    int(${start} * ${tmpN})
    ${tmpEnd}    Evaluate    int(${end} * ${tmpN} +1)
    ${outputlist}    Evaluate    [str(x*${step}) for x in range(${tmpStart}, ${tmpEnd})]
    Run Keyword If    '${outputlist[0]}' == '0.0'    Set List Value    ${outputlist}    0    0
    Run Keyword If    int(${outputlist[-1]}) == 1    Set List Value    ${outputlist}    -1    1
    [Return]    ${outputlist}
